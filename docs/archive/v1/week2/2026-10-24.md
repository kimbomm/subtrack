## 오늘의 목표
`Request` 객체를 직접 만들어 Route Handler를 호출하고, 정상·검증 실패·잘못된 JSON 케이스를 테스트한다.

## 구현 (120분)

1. 테스트 파일 (`src/app/api/subscriptions/route.test.ts`)
```ts
import { describe, it, expect, beforeEach } from 'vitest';
import { GET, POST } from './route';
import { subscriptionRepository } from '@/lib/subscriptions';

const url = 'http://localhost/api/subscriptions';

function jsonRequest(body: unknown): Request {
  return new Request(url, {
    method: 'POST',
    headers: { 'content-type': 'application/json' },
    body: JSON.stringify(body),
  });
}

const valid = { name: '넷플릭스', amount: 17000, cycle: 'monthly', startDate: '2026-10-01' };

describe('POST /api/subscriptions', () => {
  it('정상 입력이면 201과 생성된 항목을 반환한다', async () => {
    const res = await POST(jsonRequest(valid));
    expect(res.status).toBe(201);
    const body = await res.json();
    expect(body).toMatchObject({ name: '넷플릭스', amount: 17000 });
    expect(typeof body.id).toBe('string');
  });

  it('검증 실패 시 400과 필드별 에러를 반환한다', async () => {
    const res = await POST(jsonRequest({ ...valid, amount: -5 }));
    expect(res.status).toBe(400);
    const body = await res.json();
    expect(body.error.code).toBe('VALIDATION_ERROR');
    expect(body.error.fields).toHaveProperty('amount');
  });

  it('잘못된 JSON이면 400을 반환한다', async () => {
    const req = new Request(url, {
      method: 'POST',
      headers: { 'content-type': 'application/json' },
      body: '{not json',
    });
    const res = await POST(req);
    expect(res.status).toBe(400);
  });
});

describe('GET /api/subscriptions', () => {
  beforeEach(async () => {
    for (const item of await subscriptionRepository.list()) {
      await subscriptionRepository.remove(item.id);
    }
  });

  it('저장된 항목 목록을 반환한다', async () => {
    await POST(jsonRequest(valid));
    const res = await GET();
    const body = await res.json();
    expect(body.items).toHaveLength(1);
  });

  it('항목이 없으면 빈 배열을 반환한다', async () => {
    const res = await GET();
    expect(await res.json()).toEqual({ items: [] });
  });
});
```

## 학습 포인트
- 테스트 전에 저장소를 비워야 테스트끼리 영향을 주지 않는다 (`beforeEach` 활용)
- 핸들러 테스트는 HTTP 서버를 띄우지 않고 함수 호출로 검증하므로 빠르다. 실제 네트워크 검증은 E2E에서 한다
