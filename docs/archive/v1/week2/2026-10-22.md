# 10/22 (목) · 2주차 1일 — Zod 스키마와 에러 응답 규격

**유형**: 학습 + 구현 | **시간**: 2시간

## 오늘의 목표
구독 입력 스키마를 Zod로 정의하고, 검증 실패 시 필드별 에러를 반환하는 규격을 정한다.

## 학습 (30분): parse와 safeParse
- `parse(data)`: 실패하면 예외를 던진다
- `safeParse(data)`: `{ success, data }` 또는 `{ success: false, error }`를 반환한다
- API 핸들러에서는 예외 대신 결과 객체로 처리하는 `safeParse`를 쓰는 편이 흐름이 명확하다

**에러 응답 규격 (오늘 확정)**
```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "입력값을 확인해 주세요",
    "fields": {
      "name": "서비스명을 입력하세요",
      "amount": "금액은 0 이상이어야 합니다"
    }
  }
}
```

## 구현 (80분)

1. 패키지 설치
```bash
pnpm add zod
```
> Zod 버전에 따라 에러 메시지 옵션(`message` 또는 `error`)과 에러 포맷 함수 이름이 다를 수 있으니, 설치 후 공식 문서로 확인한다.

2. 테스트 먼저 작성 (`src/lib/subscriptions/schema.test.ts`)
```ts
import { describe, it, expect } from 'vitest';
import { subscriptionInputSchema } from './schema';

const valid = { name: '넷플릭스', amount: 17000, cycle: 'monthly', startDate: '2026-10-01' };

describe('subscriptionInputSchema', () => {
  it('정상 입력은 통과한다', () => {
    expect(subscriptionInputSchema.safeParse(valid).success).toBe(true);
  });

  it('서비스명이 비어 있으면 name 필드 에러', () => {
    const result = subscriptionInputSchema.safeParse({ ...valid, name: '   ' });
    expect(result.success).toBe(false);
    if (!result.success) {
      expect(result.error.issues.some((i) => i.path[0] === 'name')).toBe(true);
    }
  });

  it('음수 금액은 거부한다', () => {
    expect(subscriptionInputSchema.safeParse({ ...valid, amount: -1 }).success).toBe(false);
  });

  it('소수점 금액은 거부한다', () => {
    expect(subscriptionInputSchema.safeParse({ ...valid, amount: 10.5 }).success).toBe(false);
  });

  it('잘못된 날짜 형식은 거부한다', () => {
    expect(subscriptionInputSchema.safeParse({ ...valid, startDate: '2026/10/01' }).success).toBe(false);
  });

  it('알 수 없는 주기 값은 거부한다', () => {
    expect(subscriptionInputSchema.safeParse({ ...valid, cycle: 'daily' }).success).toBe(false);
  });
});
```

3. 스키마 구현 (`src/lib/subscriptions/schema.ts`)
```ts
import { z } from 'zod';

export const billingCycleSchema = z.enum(['weekly', 'monthly', 'yearly']);

export const subscriptionInputSchema = z.object({
  name: z.string().trim().min(1, '서비스명을 입력하세요').max(50, '50자 이하로 입력하세요'),
  amount: z.number().int('금액은 정수여야 합니다').min(0, '금액은 0 이상이어야 합니다'),
  cycle: billingCycleSchema,
  startDate: z.string().regex(/^\d{4}-\d{2}-\d{2}$/, '날짜 형식은 YYYY-MM-DD 입니다'),
});

export type SubscriptionInput = z.infer<typeof subscriptionInputSchema>;
```

## 학습 포인트
- `z.infer`로 타입을 뽑으면 스키마와 타입이 한 곳에서 관리된다 (타입 중복 제거)
- `trim()`은 검증 전에 공백을 제거한다. 공백만 입력한 값이 `min(1)`을 통과하지 않는 이유가 이것이다
