# 10/28 (수) · 2주차 7일 — Playwright 등록 E2E

**유형**: 구현 | **시간**: 2시간

## 오늘의 목표
Playwright를 설정하고, "폼 입력 → 저장 → 목록에 표시"되는 등록 흐름 E2E 1개를 완성한다.

## 학습 메모 (10분): E2E를 적게 쓰는 이유
- 느리고 불안정해지기 쉬우므로 흐름의 핵심 경로만 작성한다
- 세부 검증(검증 메시지, 에러 분기)은 이미 단위·컴포넌트 테스트에 있다

## 구현 (70분)

1. 설치
```bash
pnpm add -D @playwright/test
pnpm exec playwright install chromium
```

2. 설정 (`playwright.config.ts`)
```ts
import { defineConfig, devices } from '@playwright/test';

export default defineConfig({
  testDir: './e2e',
  use: { baseURL: 'http://localhost:3000' },
  projects: [{ name: 'chromium', use: { ...devices['Desktop Chrome'] } }],
  webServer: {
    command: 'pnpm dev',
    url: 'http://localhost:3000',
    reuseExistingServer: !process.env.CI,
  },
});
```

3. `package.json` 스크립트
```json
{ "scripts": { "e2e": "playwright test" } }
```

4. 테스트 (`e2e/subscription-create.spec.ts`)
```ts
import { test, expect } from '@playwright/test';

test('구독을 등록하면 목록에 표시된다', async ({ page }) => {
  await page.goto('/');

  await page.getByRole('textbox', { name: '서비스명' }).fill('넷플릭스');
  await page.getByLabel('금액').fill('17000');
  await page.getByLabel('시작일').fill('2026-10-01');
  await page.getByRole('button', { name: '저장' }).click();

  await expect(page.getByRole('listitem').filter({ hasText: '넷플릭스' })).toBeVisible();
});
```
> 목록 페이지(`/`)가 아직 없다면 이 날 최소한의 목록 컴포넌트를 함께 만든다.

5. 실행
```bash
pnpm e2e
```

6. 커밋: `test: 구독 등록 E2E 추가`

## 막히면 확인할 것
- 브라우저가 없다는 에러: `pnpm exec playwright install chromium` 재실행
- `webServer` 타임아웃: `pnpm dev`가 단독으로 3000 포트에서 뜨는지 확인
- 목록이 안 보이면 데이터 저장 여부를 `curl`로 먼저 확인 (2주차 2일 방식)
- 인메모리 저장소는 서버 재시작 시 초기화되므로, 같은 이름 항목이 여러 개 있어도 `filter`로 확인한다
