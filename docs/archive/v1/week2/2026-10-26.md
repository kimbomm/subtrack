# 10/26 (월) · 2주차 5일 — RTL 폼 테스트

**유형**: 학습 + 구현 | **시간**: 2시간

## 오늘의 목표
RTL로 폼의 검증 메시지와 입력·제출 흐름을 테스트한다. 쿼리는 사용자가 보는 방식(역할, 라벨) 기준으로 고른다.

## 학습 (30분): 쿼리 우선순위
RTL 공식 권장 순서:
1. `getByRole` (역할과 접근 가능한 이름)
2. `getByLabelText` (폼 필드)
3. `getByText` (일반 텍스트)
4. `getByTestId` (최후의 수단)

```tsx
screen.getByRole('textbox', { name: '서비스명' });   // 좋음
screen.getByTestId('name-input');                    // 마지막 수단
```

**왜 이 순서인가**: 역할과 라벨을 기준으로 찾으면 접근성 트리가 깨졌을 때 테스트도 실패한다. 즉 테스트가 접근성을 함께 검증한다.

## 구현 (80분)

1. 패키지 설치
```bash
pnpm add -D @testing-library/react @testing-library/dom @testing-library/user-event @testing-library/jest-dom jsdom
```

2. 설정 파일 (`vitest.setup.ts`)
```ts
import '@testing-library/jest-dom/vitest';
```
`vitest.config.ts`의 `test` 블록에 추가
```ts
setupFiles: ['./vitest.setup.ts'],
```

3. 테스트 파일 상단에 jsdom 환경 지정 (`src/components/subscriptions/SubscriptionForm.test.tsx`)
```tsx
// @vitest-environment jsdom
import { describe, it, expect, vi } from 'vitest';
import { render, screen } from '@testing-library/react';
import userEvent from '@testing-library/user-event';
import { SubscriptionForm } from './SubscriptionForm';

describe('SubscriptionForm', () => {
  it('빈 상태로 제출하면 서비스명 에러를 보여준다', async () => {
    const onSubmit = vi.fn();
    render(<SubscriptionForm onSubmit={onSubmit} />);

    await userEvent.click(screen.getByRole('button', { name: '저장' }));

    expect(await screen.findByRole('alert')).toHaveTextContent('서비스명을 입력하세요');
    expect(onSubmit).not.toHaveBeenCalled();
  });

  it('정상 입력 후 제출하면 onSubmit에 검증된 값을 전달한다', async () => {
    const onSubmit = vi.fn().mockResolvedValue(undefined);
    render(<SubscriptionForm onSubmit={onSubmit} />);

    await userEvent.type(screen.getByRole('textbox', { name: '서비스명' }), '넷플릭스');
    await userEvent.type(screen.getByLabelText('금액'), '17000');
    await userEvent.type(screen.getByLabelText('시작일'), '2026-10-01');
    await userEvent.click(screen.getByRole('button', { name: '저장' }));

    expect(onSubmit).toHaveBeenCalledWith(
      expect.objectContaining({ name: '넷플릭스', amount: 17000, cycle: 'monthly' }),
    );
  });

  it('입력창에 에러가 연결되어 있다', async () => {
    render(<SubscriptionForm onSubmit={vi.fn()} />);
    await userEvent.click(screen.getByRole('button', { name: '저장' }));

    const input = screen.getByRole('textbox', { name: '서비스명' });
    expect(input).toHaveAttribute('aria-invalid', 'true');
    expect(input).toHaveAccessibleDescription('서비스명을 입력하세요');
  });
});
```
