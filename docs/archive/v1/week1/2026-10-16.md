## 학습 (30분): describe, it, expect, test.each
- `describe`: 관련 테스트를 묶는 그룹
- `it` / `test`: 테스트 하나
- `expect(...).toBe()` (원시값), `toEqual()` (객체), `toBeCloseTo()` (소수 오차)
- `test.each`: 같은 로직을 입력 표로 반복

```ts
test.each([
  [1, 2, 3],
  [0, 0, 0],
  [-1, 1, 0],
])('%i + %i = %i', (a, b, expected) => {
  expect(a + b).toBe(expected);
});
```

**주의**: 부동소수점 계산은 `toBe` 대신 `toBeCloseTo`를 쓴다. 예: `1000 * 52 / 12`

## 구현 (80분)

1. 패키지 설치
```bash
pnpm add -D vitest @vitest/coverage-v8 vite-tsconfig-paths
```

2. `vitest.config.ts` 작성
```ts
import { defineConfig } from 'vitest/config';
import tsconfigPaths from 'vite-tsconfig-paths';

export default defineConfig({
  plugins: [tsconfigPaths()],
  test: {
    environment: 'node',
    include: ['src/**/*.test.{ts,tsx}'],
    coverage: {
      provider: 'v8',
      include: ['src/domain/**/*.ts'],
      thresholds: { lines: 90, functions: 90, branches: 90, statements: 90 },
    },
  },
});
```

3. `package.json` scripts 추가
```json
{
  "scripts": {
    "test": "vitest run",
    "test:watch": "vitest",
    "test:coverage": "vitest run --coverage"
  }
}
```

4. `src/domain/smoke.test.ts`를 만들어 러너가 도는지 확인 (10/17에 삭제)
```ts
import { describe, it, expect } from 'vitest';

describe('테스트 러너', () => {
  it('동작한다', () => {
    expect(1 + 1).toBe(2);
  });
});
```

5. `pnpm test`, `pnpm test:coverage` 실행해서 리포트 확인

6. 커밋: `test: vitest 설정과 커버리지 임계값 추가`
