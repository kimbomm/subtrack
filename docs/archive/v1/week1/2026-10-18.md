## 구현 (90분)

1. `toYearlyCost` 테스트 먼저 작성
   - 월간 10,000 → 연 120,000
   - 주간 1,000 → 연 52,000
   - 연간 120,000 → 연 120,000
   - 0원 → 0

2. 구현
```ts
export function toYearlyCost(sub: { amount: number; cycle: BillingCycle }): number {
  switch (sub.cycle) {
    case 'monthly':
      return sub.amount * 12;
    case 'yearly':
      return sub.amount;
    case 'weekly':
      return sub.amount * 52;
  }
}
```

3. 교차 검증 테스트 추가: 모든 주기에서 `toYearlyCost ≈ toMonthlyCost × 12`
```ts
test.each(['weekly', 'monthly', 'yearly'] as const)(
  '%s 주기에서 연 합계는 월 환산 × 12와 같다',
  (cycle) => {
    const sub = { amount: 5000, cycle };
    expect(toYearlyCost(sub)).toBeCloseTo(toMonthlyCost(sub) * 12, 6);
  },
);
```

## 기본기 노트 (30분): 클로저, 이벤트 루프, 마이크로태스크

**클로저**: 함수가 선언된 시점의 변수를 기억하는 성질. `var`와 `let`의 차이를 `setTimeout` 예제로 확인한다.

**이벤트 루프 퀴즈** (예측한 뒤 실행해서 확인)
```js
console.log('A');
setTimeout(() => console.log('B'), 0);
Promise.resolve().then(() => console.log('C'));
console.log('D');
// 예상 출력: A → D → C → B
```

정리할 것:
- 콜 스택이 비어야 큐의 작업이 실행된다
- 마이크로태스크(Promise then, queueMicrotask)는 매크로태스크(setTimeout)보다 먼저 실행된다
- `async` 함수 안의 `await` 이후 코드도 마이크로태스크다
