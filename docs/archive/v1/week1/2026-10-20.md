## 오늘의 목표
다음 결제일을 계산하는 `nextBillingDate`를 구현하고, 월말·연말·윤년 케이스를 테스트로 고정한다.

## 학습 (30분): Date 객체의 함정

```js
const d = new Date(2027, 0, 31);  // 2027-01-31
d.setMonth(1);                    // 2월로 설정
console.log(d);                   // 2027-03-03 (2월 31일이 없어서 3월로 넘어감)
```

정리할 것:
- `setMonth`는 존재하지 않는 날짜를 **자동으로 넘긴다**
- 시간대 때문에 날짜가 하루 밀릴 수 있으므로 **UTC 메서드**(`getUTCDate`, `Date.UTC`)를 쓴다
- 날짜 문자열 `'2027-01-31'`은 `new Date('2027-01-31T00:00:00Z')`로 파싱해서 UTC로 고정한다

## 핵심 규칙: 시작일 기준으로 n번째 결제일을 계산한다

잘못된 방식(누적 계산):
```
1/31 → 2/28 → 3/28 → 4/28 ...   (날짜가 점점 밀림)
```

올바른 방식(시작일에서 n개월 뒤를 매번 계산):
```
1/31 → 2/28 → 3/31 → 4/30 ...
```

2. 구현 (`src/domain/billingDate.ts`)
```ts
import type { BillingCycle } from './types';

function parseUTC(date: string): Date {
  return new Date(`${date}T00:00:00Z`);
}

function formatUTC(d: Date): string {
  return d.toISOString().slice(0, 10);
}

export function addMonthsClamped(base: Date, months: number): Date {
  const day = base.getUTCDate();
  const target = new Date(Date.UTC(base.getUTCFullYear(), base.getUTCMonth() + months, 1));
  const lastDay = new Date(
    Date.UTC(target.getUTCFullYear(), target.getUTCMonth() + 1, 0),
  ).getUTCDate();
  target.setUTCDate(Math.min(day, lastDay));
  return target;
}

function occurrence(start: Date, cycle: BillingCycle, n: number): Date {
  switch (cycle) {
    case 'weekly': {
      const d = new Date(start);
      d.setUTCDate(d.getUTCDate() + 7 * n);
      return d;
    }
    case 'monthly':
      return addMonthsClamped(start, n);
    case 'yearly':
      return addMonthsClamped(start, 12 * n);
  }
}

export function nextBillingDate(startDate: string, cycle: BillingCycle, today: string): string {
  const start = parseUTC(startDate);
  const base = parseUTC(today);
  let n = 0;
  while (occurrence(start, cycle, n).getTime() <= base.getTime()) {
    n += 1;
  }
  return formatUTC(occurrence(start, cycle, n));
}
```
