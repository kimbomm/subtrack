## 학습 (30분): 테스트 피라미드와 AAA 패턴
- **테스트 피라미드**: 단위 테스트(많고 빠름) → 컴포넌트·통합 테스트(중간) → E2E(적고 느림). 아래로 갈수록 실행 비용이 커지므로 로직은 가능한 한 아래 층에서 검증한다.
- **AAA 패턴**: Arrange(준비) → Act(실행) → Assert(검증). 테스트 하나는 동작 하나만 검증한다.

```ts
it('월간 구독료는 그대로 반환한다', () => {
  // Arrange
  const sub = { amount: 10000, cycle: 'monthly' as const };
  // Act
  const result = toMonthlyCost(sub);
  // Assert
  expect(result).toBe(10000);
});
```

**자기 점검**: 금액 계산 함수는 피라미드의 어느 층에서 테스트하는 것이 맞을까? 이유는?

## 구현 (80분)

1. Node.js와 pnpm 확인
```bash
node -v        # 20 이상 권장
corepack enable
pnpm -v
```

2. 프로젝트 생성 (프롬프트 답변: TypeScript Yes, ESLint Yes, Tailwind No, `src/` Yes, App Router Yes, import alias `@/*`)
```bash
pnpm create next-app@latest subtrack
cd subtrack
```

3. `tsconfig.json`에서 `"strict": true` 확인

4. Prettier 설치 및 설정
```bash
pnpm add -D prettier eslint-config-prettier
```
`.prettierrc.json` 작성 예시:
```json
{ "semi": true, "singleQuote": true, "printWidth": 100 }
```

5. `package.json` scripts 추가
```json
{
  "scripts": {
    "lint": "next lint",
    "typecheck": "tsc --noEmit",
    "format": "prettier --write ."
  }
}
```

6. `pnpm dev`로 기본 페이지 확인

7. Git 저장소 연결 및 첫 push
```bash
git init
git add .
git commit -m "chore: 프로젝트 초기 설정"
```
GitHub에서 `subtrack` 저장소를 만들고(public 권장) remote 연결 후 push
