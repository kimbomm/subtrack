## 1주차 핵심 규칙 (금액 계산)
| 규칙 | 내용 |
|---|---|
| 금액 단위 | 원(KRW), 정수 입력 |
| 주간 → 월 | `amount × 52 / 12` |
| 연간 → 월 | `amount / 12` |
| 월간 → 월 | `amount` 그대로 |
| 반올림 | 최종 출력 단계에서 원 단위 반올림 (`Math.round`) |
| 음수·NaN·Infinity | `InvalidAmountError` 던짐. 0원은 허용 (무료 체험 등) |
| 월말 결제일 | 시작일의 날짜를 기준으로 계산하고, 해당 월의 마지막 날로 보정 |
