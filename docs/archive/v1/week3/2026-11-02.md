# 11/02 (월) · 3주차 5일 — 보안 헤더, CSP, XSS 방어

**유형**: 학습 + 구현 | **시간**: 2시간

## 오늘의 목표
보안 헤더를 설정하고, 사용자 입력이 HTML로 해석되지 않는다는 것을 테스트로 확인한다.

## 학습 (30분): XSS와 CSP
- **XSS**: 공격자가 입력한 스크립트가 다른 사용자의 브라우저에서 실행되는 취약점
- **방어 원칙**: 사용자 입력은 **텍스트로 출력**한다. React는 기본적으로 이스케이프하지만, `dangerouslySetInnerHTML`을 쓰면 이 보호가 사라진다
- **CSP(Content Security Policy)**: 허용된 출처에서만 스크립트, 스타일 등을 로드하도록 브라우저에 지시하는 헤더

**토큰 저장 위치 정리 (면접용 메모)**
| 저장 위치 | 장점 | 단점 |
|---|---|---|
| 메모리 | XSS로 읽기 어려움 | 새로고침 시 사라짐 |
| localStorage | 구현이 쉬움 | XSS 시 탈취 가능 |
| HttpOnly 쿠키 | JS에서 읽을 수 없음 | CSRF 대응 필요, SameSite 설정 중요 |

> 이 프로젝트는 로그인이 없으므로 토큰이 없다. 면접에서는 "인증이 필요한 서비스였다면 HttpOnly + Secure + SameSite 쿠키를 선택하고 CSRF를 함께 막는다"라고 설명하면 된다.

## 구현 (80분)

1. `next.config.ts`에 헤더 추가
```ts
import type { NextConfig } from 'next';

const securityHeaders = [
  { key: 'Content-Security-Policy', value: "default-src 'self'; img-src 'self' data:; style-src 'self' 'unsafe-inline'; script-src 'self' 'unsafe-inline'; frame-ancestors 'none'" },
  { key: 'X-Frame-Options', value: 'DENY' },
  { key: 'X-Content-Type-Options', value: 'nosniff' },
  { key: 'Referrer-Policy', value: 'strict-origin-when-cross-origin' },
];

const nextConfig: NextConfig = {
  async headers() {
    return [{ source: '/:path*', headers: securityHeaders }];
  },
};

export default nextConfig;
```
> `'unsafe-inline'`은 Next.js 기본 동작과 호환을 위해 임시로 둔다. README에 "nonce 기반 CSP로 강화 가능, 이번 프로젝트에서는 범위 밖"이라고 기록한다.

2. 헤더 확인
```bash
pnpm build && pnpm start
curl -I http://localhost:3000
```

3. XSS 테스트 (`src/components/subscriptions/SubscriptionList.test.tsx`)
```tsx
// @vitest-environment jsdom
import { render, screen } from '@testing-library/react';
import { SubscriptionList } from './SubscriptionList';

it('서비스명에 스크립트 태그가 있어도 텍스트로 표시된다', () => {
  const payload = '<script>alert(1)</script>';
  const { container } = render(
    <SubscriptionList items={[{ id: '1', name: payload, amount: 1000, cycle: 'monthly', startDate: '2026-10-01' }]} />,
  );
  expect(screen.getByText(payload)).toBeInTheDocument();
  expect(container.querySelector('script')).toBeNull();
});
```
> `SubscriptionList`가 아직 없다면 목록 컴포넌트를 먼저 만든다.
