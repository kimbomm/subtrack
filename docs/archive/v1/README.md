# SubTrack 4주 커리큘럼 (2026.10.15 ~ 2026.11.11)

## 목표
- 테스트·CI·배포 기반을 0에서 세우고, 그 과정을 면접에서 설명할 수 있는 상태 만들기
- 캡스톤 프로젝트: 구독 관리 웹앱 **SubTrack** (Next.js App Router + React + TypeScript)

## 기간과 시간
- 기간: 2026.10.15(목) ~ 2026.11.11(수), 28일
- 주당 15시간: 평일 2시간 × 5일, 토요일 2시간, 일요일 3시간
- 총 약 60시간

## 필수 항목과 보류 항목

| 구분 | 항목 |
|---|---|
| **필수** | 단위 테스트(Vitest), 컴포넌트 테스트(RTL + MSW), E2E(Playwright), GitHub Actions CI, Branch protection, 보안 헤더(CSP), 접근성 자동 검사(axe), Vercel 배포, README |
| **보류** | Storybook, 시각적 회귀 테스트, Lighthouse CI, Sentry, 모노레포, 번들 분석 심화 |

보류 항목은 4주차 11/11 버퍼 시간에 여유가 있을 때만 진행합니다.

## 기술 스택
- Next.js(App Router), React, TypeScript(strict)
- Zod(입력 검증), Vitest, React Testing Library, MSW, Playwright, @axe-core/playwright
- pnpm, ESLint, Prettier, GitHub Actions, Vercel

## 공통 규칙
- **커밋 규칙**: 하루 최소 1커밋. 접두어 `feat:`, `test:`, `ci:`, `docs:`, `fix:`, `chore:` 사용
- **테스트 먼저**: 도메인 로직은 실패하는 테스트를 먼저 작성한 뒤 구현

- **공휴일**: 기간 내 공휴일 없음
