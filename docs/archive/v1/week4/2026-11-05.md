# 11/05 (목) · 4주차 1일 — 필터 UI와 URL 쿼리 동기화

**유형**: 구현 | **시간**: 2시간

## 오늘의 목표
결제 주기 필터와 "갱신 임박" 필터를 만들고, 필터 상태를 URL 쿼리에 저장한다.

## 설계 메모 (10분)
- 쿼리 키: `cycle=monthly|yearly|weekly`, `dueSoon=7` (7일 이내 갱신)
- URL이 상태의 원천(source of truth). 새로고침과 링크 공유가 그대로 동작한다

## 구현 (80분)

1. 필터 바 컴포넌트 (`src/components/subscriptions/FilterBar.tsx`)
```tsx
'use client';

import { useRouter, useSearchParams, usePathname } from 'next/navigation';

export function FilterBar() {
  const router = useRouter();
  const pathname = usePathname();
  const params = useSearchParams();

  function update(key: string, value: string | null) {
    const next = new URLSearchParams(params.toString());
    if (value) next.set(key, value);
    else next.delete(key);
    router.replace(`${pathname}?${next.toString()}`);
  }

  return (
    <div role="group" aria-label="구독 필터">
      <label htmlFor="cycle-filter">결제 주기</label>
      <select
        id="cycle-filter"
        value={params.get('cycle') ?? ''}
        onChange={(e) => update('cycle', e.target.value || null)}
      >
        <option value="">전체</option>
        <option value="weekly">주간</option>
        <option value="monthly">월간</option>
        <option value="yearly">연간</option>
      </select>

      <label>
        <input
          type="checkbox"
          checked={params.get('dueSoon') === '7'}
          onChange={(e) => update('dueSoon', e.target.checked ? '7' : null)}
        />
        7일 이내 갱신
      </label>
    </div>
  );
}
```

2. `useSearchParams`를 쓰는 컴포넌트는 `<Suspense>`로 감싸야 한다는 점을 확인한다 (App Router의 정적 렌더링 요구사항)
```tsx
<Suspense fallback={null}><FilterBar /></Suspense>
```

3. 수동 확인: 필터 변경 → URL 변경 → 새로고침 후 필터 유지

4. 커밋: `feat: 주기·갱신 임박 필터와 URL 동기화 추가`

## 학습 포인트
- `router.replace`는 히스토리를 쌓지 않는다. 필터 변경마다 뒤로가기가 쌓이는 것을 피하려면 `replace`를 쓴다
- 상태를 URL에 두면 테스트와 공유가 쉬워지고, 새로고침 후에도 같은 화면이 나온다

- 필터가 반영되지 않으면 목록 컴포넌트가 URL 값을 읽는지 확인 (다음 날 순수 함수와 연결)
