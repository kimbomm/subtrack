# SubTrack

> 구독 서비스의 월·연 비용을 계산하고, 갱신 임박 항목을 관리하는 웹앱

## 주요 기능
- 구독 등록, 수정, 삭제
- 월·연 비용 자동 계산 (주간·월간·연간 주기 변환)
- 결제 주기, 7일 이내 갱신 필터 (URL 쿼리 동기화)

## 해결한 문제
| 문제 | 해결 |
|---|---|
| 월말 결제일이 누적되면서 날짜가 밀림 | 시작일 기준 n번째 결제일 계산 + 월말 보정 |
| 금액 계산 규칙이 화면마다 달라질 위험 | 도메인 함수로 분리하고 단위 테스트로 고정 |
| 잘못된 입력이 서버까지 전달됨 | Zod 스키마를 서버와 클라이언트가 공유 |
| 실패한 변경이 main에 머지될 위험 | CI 필수 체크와 Branch protection |

## 테스트 전략
| 층 | 도구 | 대상 | 이유 |
|---|---|---|---|
| 단위 | Vitest | 금액·날짜·필터 함수 | 빠르고, 규칙을 가장 정확히 고정 |

## CI/CD
- PR마다 `verify` 잡(린트, 타입체크, 커버리지 테스트, 빌드) 실행
- `verify` 통과 후 `e2e` 잡 실행, 실패 시 리포트 아티팩트 업로드
- main 브랜치는 필수 체크 통과 후에만 머지 가능
- 배포: Vercel (PR 프리뷰 자동 생성)
